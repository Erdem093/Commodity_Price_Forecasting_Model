        Maturity and roadmap

        Current Limitations

        • Demo mode uses a reduced data window to stay responsive in browser sessions.
        • Serverless runtime constraints limit full in-function model training complexity.
        • Phase-1 data scope does not yet include full inventory and shipping connectors.

        Next Steps

        • Move to dedicated async queue and worker infra for robust production-grade execution.
        • Integrate additional fundamental data sources (EIA + shipping) for broader signal coverage.
        • Add production monitoring for drift, model decay, and run-level alerting.
